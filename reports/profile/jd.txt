代理 JD：Agent × 搜索/推荐算法实习

岗位目标：面向搜索、推荐与大语言模型交叉方向，构建可运行、可评测、
可解释的智能推荐系统，并能清楚说明从用户意图到候选召回、排序和反馈的完整链路。

核心能力：
- 使用 LLM Agent 完成结构化意图理解、偏好状态维护和工具规划；
- 实现搜索/推荐候选召回，包括协同过滤与稠密语义检索；
- 使用 Learning-to-Rank（如 LightGBM LambdaMART）完成候选排序和特征贡献解释；
- 建立无数据泄漏的离线评测、分组交叉验证、NDCG/Recall 指标、配对 bootstrap 和冻结测试门禁；
- 支持 OpenAI-compatible API、vLLM、单卡 RTX 4090 远程推理和超时降级；
- 提供可复现 CLI、测试、版本化配置/指纹、实验报告和 Gradio 演示；
- 能将真实实验产物整理为简历 STAR、核心代码讲解和面试问答。

项目约束：两周内推进；默认本地 CPU + API，服务器服务仅绑定本地并通过 SSH 转发；
不要求多 Agent、模型微调、向量数据库或分布式训练；所有指标必须来自可追溯实验产物。
